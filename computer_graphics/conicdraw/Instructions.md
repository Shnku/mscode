# Assignment No. 2

**Computer Graphics Laboratory: Circle and Ellipse Drawing Algorithms (Bresenham Circle, Midpoint Circle & Midpoint Ellipse)**

## Aim

To implement Bresenham's Circle drawing algorithm, the Midpoint Circle drawing algorithm and the Midpoint Ellipse drawing algorithm in C, and to compare the pixel points generated and the execution time of the two circle algorithms for an identical set of centres and radii, and to study how the ellipse algorithm generalises the circle case.

## Objectives

* Implement Bresenham's Circle, Midpoint Circle and Midpoint Ellipse algorithms exactly as taught in the theory class, in C.
* Print the pixel points generated by each algorithm for the same input data.
* Understand and demonstrate the use of 8-way symmetry for a circle and 4-way symmetry for an ellipse.
* Understand why the first quadrant of an ellipse must be divided into two regions at the point where the slope of the tangent becomes -1.
* Measure and compare the execution time of the two circle algorithms.
* Justify, in a written report, why the outputs (points / counts / time) of the two circle algorithms agree or differ, and why the ellipse algorithm reduces to the circle case when $r_x=r_y$.

## Software Required

Any standard C compiler - Turbo C, Dev-C++, Code::Blocks, GCC (command line), or an online C compiler. No graphics library is required; this assignment is console/text output only.

## Important

Implement only the three algorithms exactly as taught in the theory class. Do not use any modified, optimized, or alternate versions of the algorithms found online or suggested by AI tools. Deviating from the classroom algorithm will lead to loss of marks, even if the output is correct. In particular, Bresenham's circle must use the decision variable $d=3-2r$ and the Midpoint circle must use the decision parameter $p=1-r$; the two must not be written as the same program.

## Tasks

### Task 1: Bresenham Circle Program (`bresenham_circle.c`)

Write a C program that, for each given centre $(x_c, y_c)$ and radius $r$, generates and prints all the pixel points of the circle using Bresenham's circle algorithm (as taught in class, integer arithmetic only), applies 8-way symmetry to obtain the complete circle from the points computed in one octant, and measures and prints the execution time of the circle-generation logic using `clock()`.

### Task 2: Midpoint Circle Program (`midpoint_circle.c`)

Write a second, independent C program with the same structure as Task 1, but using the Midpoint circle drawing algorithm (decision parameter $p=1-r$) to generate and print the points, and measure its execution time on the same centres and radii.

### Task 3: Midpoint Ellipse Program (`midpoint_ellipse.c`)

Write a third C program that, for each given centre $(x_c, y_c)$ and semi-axes $r_x$ and $r_y$, generates and prints all pixel points of the ellipse using the Midpoint ellipse algorithm. The program must clearly implement the two regions of the first quadrant separately, print how many iterations were performed in Region 1 and in Region 2, apply 4-way symmetry, and measure the execution time using `clock()`.

### Task 4: Comparison and Report

Using the outputs of the three programs (run on the same test data), prepare a Word document that includes, for every test case: the printed point list, the number of points generated, the execution time, and the comparison tables described below.

## Comparison & Report Requirements

The report must contain the following two comparisons. A comparison table without justification will not be considered complete.

### Comparison 1: Bresenham Circle vs Midpoint Circle

For each circle test case, give a comparison table covering:

* Number of octant iterations performed by each algorithm.
* Total number of points generated and the number of distinct pixels produced by each algorithm.
* Execution time of each algorithm.
* Any difference in the actual point sequence generated (state clearly if there is none).

For each test case, justify in your own words why the two point sets agree or differ. Your justification is expected to discuss the relationship between the two decision variables ($d=3-2r$ and $p=1-r$), the fact that both algorithms use integer arithmetic only, and the effect of the loop-termination condition ($x \le y$ as against $x < y$) on the number of points produced.

### Comparison 2: Circle Algorithm vs Ellipse Algorithm

Give a second table comparing the Midpoint Circle algorithm with the Midpoint Ellipse algorithm on the following points:

* Symmetry used: 8-way for the circle against 4-way for the ellipse and the reason for the difference.
* Number of regions scanned: one octant against two regions of the first quadrant and the reason for the difference.
* Nature of the arithmetic: fully integer in the circle algorithm, whereas the initial decision parameters of the ellipse contain the fractional terms $\frac{1}{4}r_x^2$ and $(x+\frac{1}{2})^2$.
* Execution time for a comparable size of figure, and the reason for the difference.
* Output of Ellipse Case 3 ($r_x=r_y=25$) against Circle Case 2 ($r=25$): are the pixel sets identical? Justify the result you obtained.
