## Drawing aSimple Puja Figure using Line, Circle and Ellipse Algorithms

### Aim

To draw a simple Durga Puja figure in Python using the line, circle
and ellipse drawing algorithms already studied in the theory class.

What to Draw The figure has five parts, but only three algorithms are
needed. Use the exact coordinates given below.

|Part|Represents|Algorithm to use|Coordinates|
|---|---|---|---|  
|1|Durga's face|Midpoint circle|centre (90, 250), r = 35|
|2|Durga's body|Midpoint ellipse|centre (90, 155), rx = 45, ry = 60|
|3|Trishul (the stick)|Bresenham line|from (30, 230) to (190, 70)|
|4|Asur's face|Midpoint circle|centre (205, 95), r = 25|
|5|Asur's body|Midpoint ellipse|centre (150, 45), rx = 45, ry = 25|

Two things to check before you start.

The trishul runs at 135° to the
x-axis --- look at the two endpoints and satisfy yourself that this is so.  
And Durga's face should sit exactly on top of her body: the lowest
point of part 1 and the highest point of part 2 are both (90, 215). If
your figure shows a gap or an overlap there, your coordinates are wrong.

Plot the generated pixel points as small square markers --- do not join them with a continuous line.

### Tasks

Write ONE Python program (puja_figure\_`<your roll no>`{=html}.py)
that does the following.

* **Task 1 ---** Generate the points Write three functions, one for each
algorithm, exactly as taught in the theory class. Each function should
return the list of pixel points it generates. Use 8-way symmetry for the
circle and 4-way symmetry for the ellipse. The same circle function is
called twice (parts 1 and 4) and the same ellipse function twice (parts
2 and 5), with different arguments --- do not write them again.

* **Task 2 ---** Print the points Print the points generated by each of the
five parts, and print how many points each one produced.

* **Task 3 ---** Draw the figure Plot all five sets of points on a single
matplotlib figure with a 1 : 1 aspect ratio, and save it as a PNG file.

### Questions to Answer Answer these in your own words, in three or four

sentences each. Write them in the same document as your output.

1. How
many points did each of the five parts generate? Which part produced the
most, and why?
2. For the trishul, what are the values of dx and dy?
What is it about these two values that makes the line come out at
exactly 135°?
3. Why does a circle allow 8-way symmetry while an ellipse
allows only 4-way?
4. If the radius of Durga's face were changed from 35
to 70, roughly how many points would that circle produce? Explain your
reasoning without running the program.

Your Own Variation After the figure above is working, run your program
once more with the radius of Durga's face changed from 35 to (35 + the
last digit of your roll number), keeping everything else the same. Save
this second figure as well, and state in your document how many points
that circle produced this time.

### Instructions

1. Write the three algorithms yourself, from the steps
taught in the theory class. Do not use any readymade circle, ellipse or
line drawing routine, and do not use matplotlib patches such as Circle
or Ellipse.
2. Matplotlib is to be used only to plot the points your own
functions have generated.
3. Use a 1 : 1 aspect ratio, otherwise the
circle will look like an ellipse.
4. If you save the figure into a
folder, create that folder first, or the program will stop with a
file-not-found error.
5. Add a comment above each function naming the
algorithm it implements.
